# MeetFloo AI Meeting Bot Monorepo

Welcome to the **MeetFloo AI** workspace repository. This repository contains the complete ecosystem of applications including the desktop co-pilot app, management admin panel, and marketing landing page.

## Repository Applications

| Application | Path | Technology | Description |
|---|---|---|---|
| **Desktop App** | [`natively-cluely-ai-assistant/`](file:///c:/Dokumen/SnapServe-AI/Meeting-bot/natively-cluely-ai-assistant) | Electron, React, TypeScript, Rust | Real-time meeting co-pilot desktop app |
| **Admin Panel** | [`admin-panel/`](file:///c:/Dokumen/SnapServe-AI/Meeting-bot/admin-panel) | React, Vite, TypeScript | User management, credit granting, payment verification |
| **Landing Page** | [`landing-page/`](file:///c:/Dokumen/SnapServe-AI/Meeting-bot/landing-page) | React, Vite, TypeScript | Product landing page & download site (Handoff ready) |
| **Shared** | [`shared/`](file:///c:/Dokumen/SnapServe-AI/Meeting-bot/shared) | TypeScript | Shared types, API constants, and utilities |
| **Docs** | [`docs/`](file:///c:/Dokumen/SnapServe-AI/Meeting-bot/docs) | Markdown | Monorepo architecture & handoff guides |

## Getting Started

### 1. Admin Panel
```bash
cd admin-panel
npm run dev
```

### 2. Landing Page
```bash
cd landing-page
npm run dev
```

### 3. Desktop Application
```bash
cd natively-cluely-ai-assistant
npm run app:dev
```
