# Admin Panel Guide

The `admin-panel` application provides administrative controls for managing users, approving UTR/UPI payments, and issuing software license keys.

## Features
- **Overview Dashboard**: System-wide statistics for active users, total transcription minutes, and credit metrics.
- **User & Credit Management**: User lookup and manual credit allocation.
- **Payment Verification**: Manual UTR code inspection and one-click payment approval/rejection.
- **License Generator**: Custom license key issuance for Pro and Enterprise plans.

## Running Locally

```bash
cd admin-panel
npm install
npm run dev
```
